% Sidebar section heading: small-caps white label + thin rule
% The sidebar spans both pages, so \nopagebreak stops a heading being
% stranded at the foot of a page, away from the lines it introduces.
\newcommand{\sidesection}[1]{%
  \par\vspace{1.1em}%
  {\headingfont\bfseries\large\color{sidetext} #1}\par
  \vspace{2pt}{\color{emeraldlt}\rule{\dimexpr\linewidth-\leftskip-\rightskip\relax}{1.2pt}}\par
  \nopagebreak[4]\vspace{0.5em}\nopagebreak[4]%
}

% Main-column section heading
\newcommand{\mainsection}[1]{%
  \par\vspace{0.6em}%
  {\headingfont\bfseries\Large\color{headtext} #1}\par
  \vspace{2pt}{\color{headtext}\rule{\dimexpr\linewidth-\leftskip-\rightskip\relax}{1pt}}\par
  \vspace{0.4em}%
}

% A labelled detail line in the sidebar (icon + text)
\newcommand{\sideitem}[2]{%
  \makebox[1.3em][l]{\color{emeraldlt}#1}{\color{sidetext}#2}\par\vspace{2pt}%
}

% An outlined circle enclosing an icon, used as a motif above a sidebar section
\newcommand{\circleicon}[1]{%
  \begin{tikzpicture}
    \draw[sidetext,line width=0.9pt] (0,0) circle (0.58cm);
    \node[font=\large\color{sidetext}] at (0,0) {#1};
  \end{tikzpicture}%
}

% A centred, uppercase sidebar line. \centering would otherwise discard the
% column padding, so the text is centred inside a parbox of the padded width.
\newcommand{\sideline}[1]{%
  \par\noindent
  \parbox{\dimexpr\linewidth-\leftskip-\rightskip\relax}{%
    \centering\footnotesize\color{sidetext}\MakeUppercase{#1}}\par
  \vspace{0.35em}%
}

% A centred "LABEL: value" detail line, padded the same way as \sideline
\newcommand{\detailline}[2]{%
  \par\noindent
  \parbox{\dimexpr\linewidth-\leftskip-\rightskip\relax}{%
    \centering\footnotesize\color{sidetext}\MakeUppercase{#1}: #2}\par
  \vspace{0.25em}%
}

% Circular profile photo. Replace path with your own photo to enable.
% Falls back to initials in a circle if the file is missing.
\newcommand{\profilephoto}[1]{%
  \begin{tikzpicture}
    \IfFileExists{#1}{%
      \clip (0,0) circle (1.6cm);
      \node at (0,0) {\includegraphics[width=3.4cm]{#1}};
    }{%
      \fill[emeraldlt] (0,0) circle (1.6cm);
      \node[font=\Huge\bfseries\color{sidetext}] at (0,0) {BM};
    }
    \draw[sidetext,line width=1.5pt] (0,0) circle (1.6cm);
  \end{tikzpicture}%
}

% Heading row: title on the left (wraps freely), date right-aligned in a
% fixed-width box so long titles can never collide with the date.
% Optional arg overrides the date column width.
\newcommand{\titledate}[3][10em]{%
  \par\noindent
  \parbox[t]{\dimexpr\linewidth-\leftskip-\rightskip-#1-0.6em\relax}{\raggedright #2}%
  \hfill
  \parbox[t]{#1}{\raggedleft #3}%
  \par
}

% Company header: name, location/tenure, date range. Groups the roles beneath it.
\newcommand{\company}[3]{%
  \par\vspace{0.6em}%
  \titledate{\bfseries\large\color{headtext} #1}{\small\color{emeraldlt} #3}%
  \vspace{1pt}{\small\color{maintext}\itshape #2}\par
}

  \par\vspace{0.3em}%
  \titledate{\bfseries\color{maintext} #1}{\small\color{emeraldlt} #2}%

}

\mainsection{Profile}
I'm a Technical Product Manager with a strong foundation in firmware and
embedded systems, specialising in IoT and connected device ecosystems. Over
the past 9+ years at Olarm, I've progressed from embedded engineer to product
manager, giving me a unique ability to bridge deep technical execution with
product strategy. I work across firmware, software, and mobile teams to define
product direction, prioritise roadmaps, and deliver reliable, scalable
solutions.

A key part of my experience is ensuring that the products we design can be
successfully manufactured and deployed at scale. I've worked closely with
engineering and production teams to align product development with
manufacturing constraints, ensuring a smooth transition from concept to
production-ready hardware. In addition to product ownership, I've led software
and app development efforts in parallel with hardware development, ensuring
cohesive end-to-end product delivery.

I'm particularly passionate about building IoT products that integrate
hardware, firmware, and software into seamless user experiences---while
remaining practical, manufacturable, and scalable.
